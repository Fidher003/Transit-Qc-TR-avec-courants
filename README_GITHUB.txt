Transit Québec Trois-Rivières — paquet GitHub Pages

Contenu :
- index.html : application
- favicon.ico : icône des favoris / onglets
- apple-touch-icon.png : icône iPhone/iPad
- favicon-256.png : icône additionnelle Windows/tuile

Installation GitHub Pages :
1. Déposer ces 4 fichiers à la racine du dépôt (même dossier).
2. Dans GitHub : Settings > Pages.
3. Choisir la branche utilisée pour le site et le dossier racine (/ root), puis Save.
4. Ouvrir le site GitHub Pages.
5. Si l'ancien favicon demeure, supprimer l'ancien favori et le recréer, ou vider le cache du navigateur.

Important : index.html est la version ETAPE2_8_2 (premier mille à 9 kn SOW).
Seules les références d'icône ont été ajoutées pour ce paquet; aucun calcul n'a été modifié.
